# API — Sistema Académico UNICEN

API REST en NestJS. Ver el [README principal](../README.md) para la arquitectura, los patrones y cómo levantar todo con Docker.

```bash
npm install
npm run start:dev   # requiere PostgreSQL (docker compose up -d db) y DB_HOST=localhost
npm run build
```

Swagger: http://localhost:3000/api/docs
